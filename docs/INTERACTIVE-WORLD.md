# v0.8 — โลกที่หยิบจับได้

ผู้ใช้ปรับลำดับงานให้กราฟิกและการโต้ตอบกับวัตถุมาก่อนบัญชี แพตช์นี้จึงเป็น Three.js world ไม่ใช่แพตช์ login/cloud save

## เล่นด้วยภาพ
- ฉากใช้ Three.js + React Three Fiber เป็นโมเดล 3D จริง กล้อง orthographic มุมเฉียงให้ภาพ 2.5D โทน Cozy
- โมเดล low-poly แบบ procedural: บ้าน คลัง เตาเผา กองไฟ ไร่ และค่ายตัดไม้; ของแต่งเป็นโมเดลเช่นกัน
- ต้นไม้ขยับ กองไฟกระพริบ ควันลอย และชาวบ้านเดินพร้อมถือของ การเดินเป็น ambient animation ไม่ใช่ระบบ pathfinding/ขนทรัพยากรจริง
- แตะต้นไม้ริมป่าหรือชาวบ้านเพื่อเปิดการจัดคนทำงาน (ไม่ให้ทรัพยากรทันทีจากการคลิก)
- แตะอาคารเพื่อเปิดคำสั่ง ลากอาคารบนพื้นเพื่อย้ายฟรี ปล่อยนอกเกาะหรือผิดเงื่อนไขจะกลับที่เดิม
- ลากการ์ดภาพอาคารหรือของตกแต่งจากจุดจับลงฉาก เล็งพื้นที่ที่ไฮไลต์; แตะการ์ดแล้วแตะพื้นที่เป็นทางเลือก
- วัสดุมีภาพ SVG ใช้ได้ทั้งแตะไอคอนแถบบน แตะการ์ด หรือใช้จุดจับลากไปช่องทดลอง
- ไม่มีกริดบล็อกแสดงถาวร พื้นที่ logic เดิม 12 ตำแหน่งใช้ตรวจการวางและรักษาเซฟ
- ปุ่มรายการวัตถุใช้กับคีย์บอร์ดหรือเมื่อ WebGL เปิดไม่ได้; ไม่เอารายการข้อความมาแทนฉากในโหมดปกติ

## โครงสร้าง
- scene/layout.ts: พิกัดโลก ↔ หมายเลขพื้นที่เซฟ, ปฏิเสธพิกัดนอกแผนที่
- scene/Models.tsx: ชิ้นส่วนโมเดลสีเรียบ แยกจากกติกาและข้อความ
- scene/WorldScene.tsx: กล้อง แสง raycasting ลากวัตถุและเลือกพื้นที่
- scene/ItemArt.tsx: SVG ภาพประกอบของการ์ด/ไอคอน ไม่ต้องโหลดภาพจากเว็บภายนอก
- scene/VisualCard.tsx: drag grip สำหรับมือถือ, pointer capture, ภาพเงาขณะลาก และทางเลือกแตะ
- การวาง/ย้ายเรียก act() เดิม จึงยังตรวจพื้นที่ วัสดุ สูตร และสิทธิ์การผลิต

## งบกราฟิกและข้อจำกัด
โหลดฉากแยกด้วย lazy import; DPR สูงสุด 1.5; shadow map 1024; invalidation timer สูงสุด 30 ครั้งต่อวินาที พักเมื่อซ่อนแท็บ/ฉากอยู่นอกจอ และรองรับ reduced motion กับปุ่มพัก

ฉาก Three.js บีบอัดประมาณ 241 KB gzip จาก build เริ่มต้น เป็นค่า payload ไม่ใช่ผลวัด FPS การวัดประสิทธิภาพบนมือถือจริงและการตรวจภาพยังต้องทำ ไม่มีการอ้าง 60fps

Cloud Browser ในรอบนี้ไม่อนุญาตให้เปิดพรีวิว localhost (ERR_BLOCKED_BY_CLIENT) จึงยังไม่มีการยืนยัน screenshot/สัมผัสจริง ทดสอบอัตโนมัติครอบคลุมตำแหน่งทั้ง 12 จุด การฉายกล้องในหลายขนาดจอ และข้อจำกัดการวาง/ย้ายร่วมกับกติกาเดิม

## ตรวจบนมือถือหลัง deploy
1. เปิดเกมแล้วเห็นเกาะและโมเดล ไม่ใช่ fallback/จอว่าง
2. เลือกการ์ดกองไฟที่ล็อก ทดลองสูตร แล้วลากการ์ดภาพลงพื้นไฮไลต์
3. แตะอาคารตรวจคำสั่ง ลากไปที่ว่าง ลองปล่อยนอกเกาะและพื้นที่ไม่ถูกต้อง
4. เลื่อนคลังการ์ดด้วยตัวการ์ด แล้วลากด้วยจุดจับ เพื่อแยก scroll กับ drag
5. หมุนจอขณะไม่มีการลาก ตรวจอัตราส่วนฉากและตำแหน่งปล่อย
6. พักภาพเคลื่อนไหว/เปิด reduced motion แล้วเลือกและย้ายอาคารได้เหมือนเดิม
7. reload แล้วอาคารอยู่ตำแหน่งเดิม
