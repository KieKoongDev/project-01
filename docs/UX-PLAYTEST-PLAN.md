# Paperbound v0.5 — แผนทดสอบ UX และความสนุก

แนวคิด: มองเห็นเมืองโต → เลือกวัสดุง่าย → ทดลอง → รับผลตอบกลับ → อยากลองอีกครั้ง
เวอร์ชันนี้ทดสอบแนวคิดด้วยคำและแต้ม ไม่ต้องผลิตภาพการ์ด 1,000 ชิ้นก่อน

## สิ่งที่ทำในแพตช์นี้
- หน้าหลักสูงเท่าหน้าจอ ใช้พื้นที่เลื่อนเฉพาะคลังการ์ดและหน้าต่างรายละเอียด
- แนวนอน: เมืองซ้าย การ์ดและโต๊ะทดลองขวา; แนวตั้ง: เมืองด้านบน คลังด้านล่าง
- โต๊ะทดลองไม่เลื่อนตามการ์ด แตะเพื่อเลือกหรือลากจากจุดจับ วัสดุใช้ซ้ำได้
- วิจัย สมุดสูตร และตั้งค่าอยู่ในหน้าต่างพร้อม focus trap และปุ่มปิด
- โทนป่าสีเขียวเข้ม กระดาษครีม แต้มสีทอง และขอบเขียวสำหรับคู่ที่ยังไม่เคยค้นพบ
- UI และชื่อการ์ดภาษาไทย ค้นหาได้ทั้งไทยและอังกฤษ ฟอนต์ Itim แนบในไฟล์เกม (OFL จากแพ็กเกจ Fontsource)
- เพลง pentatonic สังเคราะห์ต้นฉบับผ่าน Web Audio เปิดหลังผู้เล่นกดเท่านั้น มีปิดเสียง ปิดเพลง และปรับระดับเสียง
- เสียงเลือก ทดลองไม่สำเร็จ สำเร็จ ได้แต้ม และเมืองขึ้นระดับ; หยุดเสียง/ฉากเมื่อซ่อนแท็บ
- เมืองขึ้นระดับเมื่อ XP และเงื่อนไขการค้นพบครบ สร้างซ้ำไม่ให้แต้ม/XP
- reduced motion ปิดแอนิเมชันฉากและเอฟเฟกต์ UI

## เป้าหมายทดสอบ (ยังไม่ใช่ผลที่พิสูจน์แล้ว)
ทดสอบผู้เล่นใหม่ 5–8 คน คนละ 10 นาที สลับแนวตั้ง/แนวนอนและเปิด/ปิดเสียง

| คำถาม | เกณฑ์เริ่มต้น | วิธีตรวจ |
|---|---|---|
| เข้าใจการผสมไหม | อย่างน้อย 80% สร้างหินเหล็กไฟได้ภายใน 45 วินาที | จับเวลาโดยไม่สอนเพิ่ม |
| อยากทดลองต่อไหม | อย่างน้อย 70% ทดลองต่ออีก 3 ครั้งหลังสูตรแรก | สังเกตการเล่น |
| เข้าใจเมืองโตไหม | อย่างน้อย 80% อธิบายได้ว่าต้องค้นพบสิ่งใหม่และผ่านเงื่อนไข | ถามหลังเล่น |
| ใช้คลังใหญ่ไหวไหม | หาและเลือกวัสดุเป้าหมายภายใน 10 วินาที | ทดสอบชุดบันทึก 1,000+ ใบ |
| เสียงช่วยหรือรบกวน | ไม่มีเสียงก่อนกดเปิด; ผู้เล่นปรับหรือปิดได้เอง | ทดสอบเสียงจริงบนมือถือ |
| หน้าจอใช้งานได้ไหม | ปุ่มทดลองไม่หลุดจอ ไม่มีการเลื่อนทั้งหน้า | 320×568, 390×844, 844×390, 1024×768 + safe area และคีย์บอร์ด |

เป้าหมายเหล่านี้เป็นสมมติฐานสำหรับ playtest ยังไม่อ้างว่ามีอัตราชนะสมดุลหรือพิสูจน์ความสนุกแล้ว

## ตรวจสอบก่อนปล่อย
- อัตโนมัติ: กติกา วิจัย ขอบเขตยุค คลัง 5,000 ใบ เมือง การแปล และ feedback ของสูตรซ้ำ/ผิด; TypeScript และ production build
- ฟอนต์ผลิตเป็นไฟล์ assets ที่อ้างอิงได้ ไม่เรียก Google Fonts ระหว่างเล่น
- ยังต้องตรวจภาพ/สัมผัส/เสียงบนอุปกรณ์จริง: cloud browser ของรอบนี้บล็อกการเปิด localhost (ERR_BLOCKED_BY_CLIENT)
- 100dvh และ safe-area เตรียมไว้แล้ว แต่พฤติกรรมคีย์บอร์ดแต่ละเบราว์เซอร์ยังต้องตรวจจริง
- ตรวจ Railway ล่าสุด 12 ก.ย. 2026: deploy จาก main สำเร็จ และ source ยังเป็น main; v0.5 ส่งขึ้น testing จึงยังไม่อยู่บนเว็บจนกว่าจะรวมแพตช์หรือเปลี่ยน source ตามการอนุญาต

## ลำดับถัดไปหลังได้ผลทดสอบ
1. ปรับขนาดฉาก/การ์ด ความดังและจังหวะตามผู้เล่นจริง
2. เพิ่มคำอธิบายสูตรเฉพาะและชุดไอคอนตาม ART-DIRECTION โดยแยกจากรหัสการ์ด
3. เพิ่มเหตุการณ์และยุคตามข้อมูล; ไม่เพิ่มเศรษฐกิจเมืองที่บังคับให้เฝ้าจอในแพตช์นี้
4. Multiplayer, offline PWA และบุคคลสำคัญตามยุคเป็นงานแยก ยังไม่เปิดใช้ในต้นแบบนี้
