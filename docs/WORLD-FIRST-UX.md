# v0.12 · World-first UX และคิววิจัย

## จุดประสงค์ของรอบนี้

หน้าหลักต้องรู้สึกว่า “กำลังดูแลโลก” ไม่ใช่ “กำลังกดเมนู” ใน portrait ฉาก 2.5D จึงกินพื้นที่ทั้งหมดใต้ header และ resource bar ส่วนเครื่องมือเป็น bottom drawer ที่เหลือ handle 60px เมื่อปิด Landscape ยังคงฉากซ้าย/เครื่องมือขวาเพื่อใช้พื้นที่กว้างได้ดี

## Interaction loop

1. แตะวัตถุในโลกเพื่อเก็บ ดูสถานะ ย้าย หรือเปิดงานที่เกี่ยวข้อง
2. ลาก drawer ขึ้นหรือแตะ handle เพื่อเปิดการ์ด เมื่อตั้งใจวางอาคาร/ของแต่ง drawer ย่อลงเอง
3. จับคู่วัตถุดิบที่โต๊ะวิจัย วัตถุดิบถูกจองทันที สูตรยังไม่เปิดจน countdown จบ
4. กองไฟเพิ่มคิววิจัยเป็น 2 และเตาเผาเพิ่มเป็น 3 งาน แต่ทุกงานยังทำตามลำดับเพื่ออ่านสถานะง่าย
5. แตะโต๊ะวิจัย 2.5D หรือป้าย countdown เพื่อกลับสู่ drawer วิจัย การกลับเข้าเกมเรียก sync และทำงานที่หมดเวลาให้เสร็จครั้งเดียว
6. เลือกหรือลากการ์ดชาวบ้านไปวางบนการ์ดงาน คนหนึ่งมีงานเดียวและกลายเป็นผู้เชี่ยวชาญสายนั้น ผลิตต่อทุก 30 วินาทีขณะ AFK จนคลังเต็ม
7. กล่องของฝากจากการสำรวจเปิดฟรีทุก 3 นาที ผลลัพธ์เป็นไม้, ดิน/หิน, ของแต่งฟรี หรือผู้มาเยือนหากมีที่พัก ไม่มีการซื้อเงินจริง

## กติกาความปลอดภัยของ state

- Research queue เก็บ recipe ID, คู่ทรัพยากร และเวลา absolute; restore ตรวจคู่สูตร ระยะเวลา ลำดับ และ ID ซ้ำ
- งานรายคนเป็น source สำหรับ rebuild จำนวนคนในแต่ละงาน ป้องกันคนนับซ้ำ
- ของแต่งที่สุ่มได้ถูกทำเครื่องหมายตาม tile; เมื่อเก็บคืนจะกลับเป็นของฝาก ไม่แปลงเป็นวัตถุดิบฟรี
- การผลิตและ AFK ยังจำกัด 4 ชั่วโมงและเพดานคลังตามเดิม กล่องสำรวจไม่สะสมการเปิดย้อนหลัง

## สิ่งที่ต้อง playtest บนอุปกรณ์จริง

- 320×568 และ 390×844: drawer ปิดแล้วโลก/เป้าหมาย/land navigation ไม่บังกัน
- swipe handle, scroll ภายใน drawer, drag คนไปงาน และ drag การ์ดไปฉากไม่แย่ง gesture กัน
- แตะโต๊ะวิจัย, node badge และอาคารใกล้ขอบจอได้อย่างน้อย 44px
- landscape 844×390 ยังไม่รับ transform ของ mobile drawer
- reduced motion ปิด pulse/reveal และ FPS ระหว่างชาวบ้านเดิน + research badge

Automated checks ยืนยันกติกาและ build เท่านั้น ไม่ถือเป็นการยืนยัน visual QA หรือความสนุก ต้องเก็บเวลา session, จำนวนครั้งที่เปิด drawer, งานวิจัยที่เริ่ม/ยกเลิกจากความตั้งใจ และช่วงที่ผู้เล่นไม่รู้จะทำอะไรในการ playtest ถัดไป
