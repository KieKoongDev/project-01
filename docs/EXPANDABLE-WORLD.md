# v0.11 · พื้นที่และวัตถุ

รุ่นนี้เป็นขั้นแรกของแผน Object-driven world ไม่ใช่ระบบวิจัยหรือสายเหมืองครบชุด

## เล่นอย่างไร

1. เปิดแท็บพื้นที่ ซื้อป่าตะวันตก (ไม้ 12 หิน 8) แล้วเนินหินตะวันออก (ไม้ 20 หิน 16) ได้พื้นที่เพิ่มครั้งละ 12 ช่อง รวม 36 ช่อง
2. แตะชื่อพื้นที่ใต้ฉากเพื่อเลื่อนกลับศูนย์กลางของพื้นที่นั้น ใช้ปุ่ม +/− เพื่อซูม หรือเปิดไอคอนมือเพื่อลากหนึ่งนิ้ว/บีบสองนิ้ว การแตะโมเดลและลากอาคารหยุดชั่วคราวขณะอยู่ในโหมดมือ
3. แตะต้นไม้/แหล่งหิน/แหล่งดินที่ขอบเหนือของพื้นที่ ดูเวลานับถอยหลังและกดเก็บของ
4. แต่ละแหล่งผลิต 2 หน่วยทุก 60 วินาที เก็บไว้เฉพาะจุดได้สูงสุด 6 หน่วย โดยยังไม่เข้าคลังกลาง
5. อัปเกรดด้วยไม้ 8 หิน 8: รอบเหลือ 30 วินาที เก็บได้ 12 และเลือกเปิดส่งเข้าคลังอัตโนมัติได้ หากคลังเต็มยังเก็บของไว้ที่จุดตามความจุ
6. แตะอาคารแล้วหมุน 90 องศาหรือย้ายฟรีข้ามพื้นที่ ของแต่งอยู่ที่เดิม

## ขอบเขตและเหตุผล

- ใช้สาม chunk ขนาด 4×3 ใน MVP เพื่อคงตำแหน่งเซฟเดิม ไม่ใช้ขนาด 6×6 ตามแนวคิดก่อนหน้าในแพตช์นี้
- ใช้ทรัพยากรที่มีอยู่ซื้อที่ดินชั่วคราว ยังไม่มี Development Point
- แหล่งหินไม่ใช่เหมืองแร่ทองแดง และทุกพื้นที่ยังใช้สูตรยุคหินเดิม
- งานคนแบบ v0.10 ยังผลิตเข้าคลังตามเดิม แหล่งทรัพยากรใหม่เป็นระบบวัตถุที่เพิ่มเข้ามา ยังไม่ย้ายเศรษฐกิจทั้งหมดไป inventory รายอาคาร
- ไม่มีการเพิ่มคิววิจัยหลายหัวข้อ สัตว์ ระบบขาย หรือสูตรโลหะในรุ่นนี้
- AFK ใช้เวลาในอุปกรณ์และมีขอบเขต 4 ชั่วโมง ไม่ใช่ระบบเซิร์ฟเวอร์กันโกง และไม่ใช่การยืนยัน PWA เปิดเกมแบบไร้อินเทอร์เน็ตได้

## โครงสร้าง

land.ts กำหนดพื้นที่ ตำแหน่ง และข้อมูลแหล่งทรัพยากร; model.ts เก็บ rotations ขนานกับ plots และ nodes ที่มี ID คงที่; layout.ts รับจำนวนพื้นที่ที่เปิดสำหรับ raycast; ResourceNodes.tsx แสดงโมเดลและ anchor ของปุ่ม DOM; LandPanel.tsx แสดงซื้อพื้นที่และรายละเอียดจุดเก็บของ

เซฟเก่าเพิ่ม orientation ศูนย์ และจุดทรัพยากรเริ่ม cooldown ใหม่ ไม่มีของย้อนหลังฟรี ยังคง SAVE_KEY เดิมและสำเนาสำรอง ระบบตรวจ shape ของพื้นที่และ node ID ก่อนเปิดเซฟ

## ตรวจสอบก่อนขยายต่อ

Automated: ขยายจ่ายครั้งเดียว, ปฏิเสธพื้นที่ล็อก, mapping ทุกช่องทั้ง 3 พื้นที่, ย้ายรักษาทิศและ terrain, cooldown, เก็บไม่ซ้ำ, เก็บบางส่วนเมื่อคลังใกล้เต็ม, upgrade/automation, สต็อกเก่าเกินเพดานไม่หาย, migration และข้อมูลผิดรูปแบบ

Manual ยังต้องทำ: มือถือ portrait 320×568/390×844, landscape 844×390, การบีบ/ลาก/ปล่อยนอกฉาก, กลับศูนย์กลางพื้นที่, การ์ด drop หลังเลื่อนกล้อง, ไอคอนทับกัน, รายการสำรอง/คีย์บอร์ด, reduced motion และ FPS อุปกรณ์จริง ห้ามถือว่า build/tests ยืนยัน visual QA แล้ว

คิววิจัยจากการ์ดผสมและป้ายเหนือสถานีส่งมอบแล้วใน v0.12 ขั้นถัดไปคือเหมืองแร่จริง สายผลิต Tier 2 และการวัดผล playtest ของ loop โลกเต็มจอ
